# Skill Testing QA

## Purpose

Use this skill for validation, testing and quality review.

## Test Areas

- Auth.
- Permissions.
- Book catalog.
- Rentals.
- Returns.
- Notifications.
- Chatbot graph.
- MCP tools.
- Security-Audit-MCP (input/output auditing).

## QA Checklist

1. Verify at least 7 of 10 use cases.
2. Verify unauthorized access is blocked.
3. Verify stock changes on rental.
4. Verify stock restores on return.
5. Verify notification generation.
6. Verify chatbot states.
7. Verify MCP fallback.
8. Verify prompt injection attempts are blocked by Security-Audit-MCP.
9. Verify sensitive data exposure attempts are sanitized by Security-Audit-MCP.
10. Verify README matches implementation.
