# User Story — US-002 — Registrar riesgos en el rol de Technical Writer

*(Possible statuses: Draft, Planned, Approved, In Progress, Implemented, Validated, Rejected)*

## User Story

Como arquitecto, quiero agregar una sección en el rol de technical-writer que registre todos los riesgos que hay, para que los riesgos técnicos detectados (warnings de seguridad, dependencias vulnerables y otros) queden registrados de forma consistente y persistente a lo largo del ciclo de vida del proyecto.
